    <h1>Book-Haven: Online Library System</h1>
    <p>Welcome to <strong>Book-Haven</strong>, an online library system that allows users to borrow books, manage their profiles, and access various features for efficient library management.</p>
    <h2>Features</h2>
    <h3>User Features</h3>
    <ul>
        <li><strong>Signup & Login:</strong> Create accounts and log in to access user dashboards.</li>
        <li><strong>Browse Books:</strong> Explore available books in the library.</li>
        <li><strong>Borrow Books:</strong> Borrow books online through a simple process.</li>
        <li><strong>Book Renewal:</strong> Renew borrowed books with ease.</li>
        <li><strong>Profile Management:</strong> Manage personal user information.</li>
    </ul>
    <h3>Admin Features</h3>
    <ul>
        <li><strong>Dashboard:</strong> Comprehensive admin dashboard for managing library operations.</li>
        <li><strong>Add Books:</strong> Add new books to the library catalog.</li>
        <li><strong>Edit Books:</strong> Update book details like title, author, and availability.</li>
        <li><strong>Manage Borrowed Books:</strong> Track and manage borrowed books.</li>
        <li><strong>View Results:</strong> Monitor user activity and book statistics.</li>
    </ul>
    <h2>File Structure</h2>
    <h3>Folders</h3>
    <ul>
        <li><strong>CSS:</strong> Contains stylesheets for the frontend.</li>
        <li><strong>js:</strong> JavaScript files for interactivity.</li>
        <li><strong>backend:</strong> Backend logic for database and server-side operations.</li>
        <li><strong>book_covers:</strong> Stores image files for book covers.</li>
    </ul>
    <h3>Key HTML Files</h3>
    <ul>
        <li><code>Home.html</code>: Homepage for users.</li>
        <li><code>Signup.html</code>: User signup page.</li>
        <li><code>admin_dashboard.html</code>: Admin panel for managing the library.</li>
        <li><code>Edit_books.html</code>: Interface for editing book details.</li>
        <li><code>add_books.html</code>: Page for adding new books to the library.</li>
        <li><code>borrowed_books.html</code>: Displays the list of books currently borrowed by users.</li>
        <li><code>profile.html</code>: User profile management page.</li>
    </ul>
    <h2>Technologies Used</h2>
    <ul>
        <li><strong>Frontend:</strong> HTML, CSS, JavaScript</li>
        <li><strong>Backend:</strong> Python and the Django framework for server-side operations and database management</li>
    </ul>
    <h2>Installation and Setup</h2>
    <ol>
        <li>Clone the repository:
            <pre><code>git clone https://github.com/username/Book-Haven.git</code></pre>
        </li>
        <li>Navigate to the project directory:
            <pre><code>cd Book-Haven</code></pre>
        </li>
        <li>Set up dependencies and run the project:
            <pre><code>pip install -r requirements.txt</code></pre>
            <pre><code>python manage.py runserver</code></pre>
        </li>
        <li>Access the application in your browser:
            <pre><code>http://localhost:8000</code></pre>
        </li>
    </ol>
